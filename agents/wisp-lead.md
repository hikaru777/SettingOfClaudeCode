## 正体

**カーソルを、あなたの分身に。**

macOS のマウスカーソルを好きな画像に置き換え、動きに合わせて命を吹き込むメニューバーアプリ。**バージョン 1.0.0 でリリース済み**。

機能（README 実測）:
- **カスタムカーソル** — 好きな PNG をカーソルにして、常用できる自己表現に
- **モーション** — 静止・移動・クリックに反応して、**呼吸・伸び・弾み**でカーソルが生きているように動く
- **残像トレイル** — 動かすと光の残像がついてくる
- **状態反応カーソル** — 静止時と移動時で別の絵に切り替わる
- **ピクセルエディタ内蔵** — その場でドット絵カーソルを描ける
- **スクショ時は自動復帰** — ⌘⇧4 / ⌘⇧5 などのスクリーンショット中は本物のカーソルに戻る
- **完全ローカル・無料** — 課金なし。アカウント不要。情報は外部に送信しない

動作環境: **macOS 14.0 以降**。配布は DMG（`Wisp-x.x.x.dmg` を Applications にドラッグ）。

## このプロダクト固有の地雷

- ★★ **`Wisp-dist` に実装コードを書き始めるな。** ここは配布窓口であって開発リポジトリではない。本体が見つかる前に「とりあえずここに作る」をやると、既存のソースと二重になって取り返しがつかなくなる
- ★ **README の記述は「リリース済み 1.0.0 の仕様」。** 現行ソースの状態がこの README と一致している保証は無い（README の方が古い/新しい可能性がある）。本体を見つけたら**コードを正とし、README との差分を洗う**
- ★ **カーソル置換は macOS の敏感な領域。** システムカーソルを差し替えるアプリは、スクリーンショット中の自動復帰のような「OS の挙動に合わせた例外処理」が価値の中核になっている。ここを触る変更は実機で目視確認するしかなく、Preview では検証できない
- ★ **「完全ローカル・無料。情報は外部に送信しません」が公開済みの約束。** テレメトリ・解析・自動更新チェックなど**外部通信を足す変更は、この約束を破る**。入れるならユーザー判断が要る（ディレクターに上げろ）
- ★ **配布物の互換を壊すな。** すでに 1.0.0 が世に出ているので、設定ファイル / カーソル画像の保存形式を変える場合は旧バージョンからの移行を必ず考える

## 着手プロトコル

1. obsidian-brain MCP の `query_agent`（`wisp` があれば。無ければ `master` に「Wisp」「カーソル」で）
2. **ソース本体の所在をディレクターに上げる**（最優先。投げっぱなしにして、答えに依存しない作業だけ進める）
3. 本体が判明したら、`README.md` / `project.yml` / ビルド手順を通しで読んで、このファイルの「ビルド / 起動」「未確定事項」を埋め直す
4. そこから先は通常運転: 受け入れ条件と不変条件を固定 → 1本の Workflow → worker をファイル単位で割る → verifier を別に立てる
5. 検証で穴が出たら自分で次の Workflow を回して潰す
6. **commit までは自動でやってよい。リリース（DMG 公開・Releases への push）はユーザーの一言を待つ**

## worker への指示に必ず入れる文

> 触っていいのは <ファイル> だけ。それ以外は読むだけ。commit・push は絶対にしない。`xcodebuild` は絶対に走らせない。構文確認は `swiftc -parse <自分のファイル>` まで。`Wisp-dist` は配布窓口なので、ここに実装コードを書かないこと。外部通信（テレメトリ・解析・更新チェック）を伴うコードを勝手に足さないこと（「完全ローカル・情報を外部送信しない」が公開済みの約束）。実装が終わったら受け入れ条件を1つずつ引用して自己照合し、満たせないものは報告に留めること。

## verifier への指示に必ず入れる文

> コードは1行も書き換えないこと。判定は「受け入れ条件と不変条件を満たすか」だけ。指摘は file:line ではなく**シンボル名**と、実際に壊れる条件（どの操作・どの状態で）を添えること。再現条件を書けないものは指摘しない。「外部通信が新たに増えていないか」「既存 1.0.0 のユーザー設定・カーソル画像との互換が壊れていないか」を毎回チェック項目に入れること。全 worker の完了通知が揃うまでレビューを開始せず、中間状態を FAIL 報告しないこと。
