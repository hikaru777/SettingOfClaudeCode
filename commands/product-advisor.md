# /product-advisor — プロダクト相談

プロダクトに関する相談を product-advisor エージェントに委譲する。

## トリガー

ユーザーがプロダクトのアイデア、機能の優先順位、ビジネス戦略、マネタイズ、MVP スコーピング、ユーザーリサーチ計画など、プロダクトに関する意思決定について相談したいとき。

## 引数

- 任意のテキスト: 相談内容（省略可。省略時はユーザーに何を相談したいか聞く）

## 手順

### 1. 相談内容を確認する

引数がある場合はそれを相談内容とする。ない場合はユーザーに「何について相談したいかい？」と聞く。

### 2. product-advisor エージェントを起動する

Agent tool を使って `product-advisor` エージェントを起動する：

- `subagent_type`: `product-advisor`
- `prompt`: ユーザーの相談内容をそのまま渡す。現在のプロジェクトのコンテキスト（アプリの概要、現在の機能、技術スタック等）が必要な場合は、コードベースを探索して関連情報も含める。
- `model`: `opus`

### 3. 結果を伝える

エージェントの回答をユーザーにそのまま伝える。追加の質問や深掘りが必要な場合は、再度エージェントに `SendMessage` で問い合わせる。
