QUITTR型（痛み起点・10日MVP・即課金壁・インフルエンサー$3k投下）を、hondahikaruの価値観に翻訳したプレイブック。

**Why:** 彼は体験創造型・「足すな磨け」・采配者アイデンティティを持ち、QUITTR型の5要素と衝突する。核の再現性メカニズムだけ残して戦術を差し替える設計が必要。

**How to apply:** 次に彼が個人開発の拡散・収益化戦略を相談してきたら、このプレイブックを参照する。特に以下の推奨を覚えておく:

- 次の一打は「発信インフラ（obsidian-brain + Love Machine）を21日で完成させてから全プロダクトを流す」C案
- 候補プロダクト: Protagonist（動詞「主人公になる」が既に立っている）
- 翻訳の核: 痛み→欲望、10日MVP→10日で動詞の核プロトタイプ、即課金壁→体験壁、$3k投下→自作発信装置、セキュリティ後回し→最初から
- 期限切り: 発信インフラ21日超えたらProtagonistをB案で先行させる

共通動詞体系（AGEYO / Anvil / Protagonist / UIBuilder）で相互流入させるアイデアも保持。
